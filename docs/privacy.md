# Privacy

MatchGuard is designed to minimize sensitive data collection.

Recommended defaults:

- collect gameplay telemetry instead of desktop screenshots;
- avoid collecting chat or voice unless a moderation feature requires it;
- hash or pseudonymize player identifiers when possible;
- set short retention windows for raw events;
- store moderator decisions separately from raw telemetry;
- document what events are collected in the game's privacy policy.

The project should not encourage invasive client surveillance. Server-side telemetry and replay review are safer defaults for both developers and players.
