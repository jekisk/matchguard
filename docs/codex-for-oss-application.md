## Project summary

MatchGuard is an open-source toolkit for indie multiplayer games to collect server-side match telemetry, prioritize player reports, and create review-ready moderation cases without automatic bans. It provides SDK examples, event schemas, risk scoring, and moderation workflows for small teams that cannot build dedicated anti-cheat infrastructure.

## Role

Maintainer and original author.

## Why the repository matters

Small multiplayer game teams often lack anti-cheat and moderation infrastructure. MatchGuard gives them a transparent, privacy-aware starting point: collect gameplay events, identify suspicious patterns, and route cases to human review. The project is open-source so studios can audit the logic, tune thresholds, and adapt it to their engines.

## How Codex would help

Codex would help maintain the Python scoring engine, Unity and Unreal SDK examples, schema changes, tests, documentation, and issue triage. It would also help review security-sensitive pull requests and generate release notes for contributors.

## API credit usage

API credits would be used for maintainer workflows: PR review, issue triage, release notes, SDK documentation, test generation, and moderation-case summarization for sample datasets. The credits would support open-source development and examples, not private commercial surveillance.
