# Roadmap

## v0.1 - MVP

- Rule-based Python scoring engine.
- JSONL analyzer.
- Event schema.
- Unity example.
- Documentation and tests.

## v0.2

- FastAPI server packaging polish.
- Configurable scoring profiles per game mode.
- Discord webhook integration.
- Additional sample scoring profiles.
- CLI output options for saved reports and summaries.
- Unreal Engine example.

## v0.3

- Dashboard prototype.
- Replay timeline markers.
- Feedback labels for confirmed and false-positive cases.
- Example datasets for FPS and top-down games.

## Later

- Pluggable ML anomaly models.
- Studio-specific rule profiles.
- Hosted demo.
- Security review guide for game integrations.
